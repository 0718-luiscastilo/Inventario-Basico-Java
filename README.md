Inventario Básico en Java

## Descripción
Este proyecto es una aplicación de consola desarrollada en Java que simula un sistema básico de inventario para una tienda.

Permite registrar productos, calcular su valor total y detectar aquellos con bajo stock.

---

## Funcionalidades

- Registro de múltiples productos
- Almacenamiento de:
  - Nombre
  - Precio
  - Cantidad
- Cálculo del valor total por producto
- Cálculo del valor total del inventario
- Identificación de productos con bajo stock (menos de 5 unidades)
- Conteo de productos con bajo stock

---

## Conceptos aplicados

- Variables y tipos de datos
- Arreglos (arrays)
- Bucles (`for`)
- Estructuras condicionales (`if`)
- Funciones (métodos)
- Entrada y salida de datos con `Scanner`
